# V1.2 intake and fulfillment

Successful orders route into product-specific intake workflows.

## Routes
- driver-data-review -> digital analysis intake
- data-video-deep-dive -> digital analysis intake
- track-intelligence-pack -> digital analysis intake
- track-coaching-session -> coaching intake
- arrive-drive-deposit -> driver onboarding

## Production intake API
POST /intake

Recommended Cloudflare bindings:
- ALLOWED_ORIGIN=https://socalnmotorsports.store
- KV namespace binding: INTAKES
- optional INTAKE_NOTIFY_URL pointed to the SoCal AI/local ingestion gateway

The Square webhook remains the payment authority. A browser return to success.html is not proof of payment.

## Large uploads
Do not proxy AIM/video through GitHub Pages or KV. After intake, mint signed upload URLs for R2/S3 or a protected local ingestion gateway. When upload completes, emit customer.media.ready so the local AI platform can create the analysis task automatically.
